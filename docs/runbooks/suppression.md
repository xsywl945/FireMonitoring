# 灭火闭环实物验收

主机程序、执行节点和报警节点先按仓库 README 启动。水泵管路第一次不接水。电子件、舵机和摄像头用塑料膜或挡板挡住，避免试喷时淋湿。现场留一个人盯着急停。急停按下后要先松开，再按执行节点上的复位键，最后由管理员在「灭火控制」页解锁，系统才回到监视。

俯仰命令是 0 到 6000 百分度，水平是 -12000 到 12000，和执行节点协议一致。世界坐标用标定控制点的坐标系，单位是米，z 向上。

## 1. 激光自标定

不接水。激光和喷嘴同轴，标定过程只开激光。

1. 用卷尺量云台转轴中心在教室坐标系里的大致位置，精确到大约 5 厘米，作为初值。不需要量舵机零点和比例。
2. 在「灭火控制」页选择教室，管理员打开激光自标定，填这个初值。
3. 让云台依次转到 15 到 20 组不同的水平和俯仰。每组都要落在协议允许的角度里，俯仰不要挤在同一个窄区间。
4. 每组先拍一张激光关闭的画面，再打开激光。四路摄像头用红色饱和度和帧差找出红点，沿用现有三角化得到三维点。
5. 把每组的水平百分度、俯仰百分度和三维坐标贴进页面的样本框，提交拟合。
6. 看每点残差。残差稳定在几毫米量级后，参数写入 `runtime/gimbal.json`。残差明显偏大时，先检查控制点坐标和红点有没有被反光干扰，不要靠手改比例凑数。

命令行做同一件事：

```bash
python -m fire_monitoring_inference.suppression.cli calibrate --p0 1.2,0.4,2.3 --samples laser.json
```

`laser.json` 是数组，元素为 `pan_cdeg`、`tilt_cdeg` 和 `xyz`。

## 2. 试喷拟合弹道

激光标定完成后再接水。第一轮用低压、短时，喷口前方不要放电子设备和纸质标定板。

1. 选 3 到 4 个俯仰角，水平角固定。每个角度喷一次，单次不超过页面上的喷射时长。
2. 落点用两种方式之一记录：摄像头在落点区域做帧差再三角化，或者用卷尺量落点到喷嘴正下方的水平距离。
3. 在页面或命令行提交俯仰角和落点距离，拟合初速和阻力系数。

```bash
python -m fire_monitoring_inference.suppression.cli fit-drag --samples landings.json
```

`landings.json` 的元素为 `pitch_deg` 和 `range_m`。

## 3. 目标点命中

1. 在地面放一个明确的目标点，坐标用卷尺读进教室坐标系。目标要在云台射程内。
2. 第一次只开激光，确认光点靠近目标，再允许喷水。
3. 喷水后看落点和目标的偏差。偏差大时用落点修正再喷一次，不要连续空喷。
4. 页面若显示「超出喷射范围」，只报警，不喷水。
5. 有人站在火点附近时不喷，并播放撤离提示。配电间这类默认禁水的房间，即使没有千问结果也不能喷。

验收时记录：自标定残差、试喷俯仰角和落点、目标点偏差、急停到停水的现象。这些数留给实验记录，不写进程序配置。
