# 测试报告

报告范围是仓库里已经有的自动测试，以及 `docs/experiments` 中已经生成的结果。没有在本次重新发明实验数据。实物试验没有做的，写为待做。

程序界面称火情监控。本报告不把演示模式或合成脚本的输出写成现场性能。

## 1. 结果分成三类

| 类别 | 内容 | 能不能当作现场结论 |
|---|---|---|
| CI 自动测试 | `.github/workflows/ci.yml` 的 server、inference、web、firmware、ml | 说明对应代码路径按测试断言工作。不是教室里的火 |
| 离线模型评测 | `docs/experiments/2026-11-04-yolo26s` 与 2026-11-08 交接 | 公开数据集上的检测指标。本次没有重新训练或重新评测 |
| 合成或固定假响应 | `docs/experiments/2026-11-15-*` 和 `2026-11-08-variable-layout.json` | 文件内写了「合成数据」或「固定假响应」。不是受控火、不是出水 |

待做的实物实验：

- 教室中用卷尺核对的定位误差。
- MediaMTX 四路画面的现场延迟。
- 水泵是否实际出水，以及急停到停水的现场现象。
- 批准后的受控小火。脚本不会代替保卫处批准、灭火器和监护。
- 千问对真实图片的调用结果。真实调用的 `result.json` 按实验说明不提交进仓库。

## 2. CI 测试项

五个 job 都在 `ubuntu-latest` 上运行。本报告列出测试在检查什么，不把某一次本地运行的耗时写成指标。

### server

安装 `apps/server[dev]`、OpenCV 和 SciPy 后执行 `python -m pytest apps/server/tests`。

| 文件 | 检查 |
|---|---|
| `test_api.py` | 登录、教室绑定、标定写入、配置接口不返回密钥 |
| `test_alerts.py` | 确认告警时的定位、关键帧、研判、短信和水泵记录；E 类拒绝喷水；关闭短信和大模型时不调用 |
| `test_calibration.py` | 标定板页尺寸、合成 ChArUco 恢复内参、合成标记恢复外参、内参不足时不定位 |
| `test_clips.py` | 告警前 5 秒、后 10 秒的片段窗口，以及 mp4 写入 |
| `test_config.py` | 示例配置可加载、未知字段被拒绝、启用水泵必须有串口和教室、更新配置时保留密钥 |
| `test_duty.py` | 值班员不能管理用户和配置；数据库中改过的密码在重启后保留；处置状态、CSV 和 PDF |
| `test_demo.py` | 三个合成剧本的状态顺序、定位误差、禁水和有人；值班员不能开始剧本 |
| `test_health.py` | 合成帧上的冻结、模糊和离线 |
| `test_localization.py` | 观测像素和协方差、两到四路可定位、少于两路为 `UNOBSERVABLE` |
| `test_pipeline.py` | 只保留最新帧、按目标帧率取帧、千问未返回前不喷、检测线程失败后健康检查为不可用 |
| `test_streams.py` | MediaMTX 配置对 USB 使用推流、对 RTSP 使用拉流 |
| `test_suppression.py` | 模拟设备上的确认、瞄准、喷射和扑灭；电气房间无千问结果时不喷水 |
| `test_static.py` | 静态页面不挡住登录接口 |

P9 在 server job 中增加两步，不新增 job 名：用 pwsh 解析 `scripts/windows` 下的 PowerShell；运行 `scripts/docs/build_materials.py --check`，核对源程序行数和 PDF 页数。

### inference

`python -m pytest apps/inference`。

| 文件 | 检查 |
|---|---|
| `test_temporal.py` | 按类别的 N/M 确认、冷却，以及非法阈值顺序被拒绝 |
| `test_rules.py` | A 到 F 类的灭火剂允许和禁止；带电为 E 类；实验室未知时提高 B 类和 D 类 |
| `test_suppression.py` | 自标定恢复云台参数、弹道逆解、覆盖概率、急停锁定到管理员解锁、各联锁拒绝喷水、椭圆扫射盖不住时不喷 |
| `test_actuator_v2.py` | 急停在复位和主机解锁前拒绝 `RUN`；心跳超时关泵和激光；瞄准角速度限制 |
| `test_panel_v2.py` | 链路中断后黄红交替，直到主机再次发报文；静音只影响蜂鸣 |
| `test_pump.py` | 同一次 `RUN` 不重复；应答不确定时不换同一 id 重试；急停持续发送停止直到设备确认关闭 |
| `test_growth.py` | 合成热释放与增长档位；过短窗口被拒绝 |
| `test_size.py` | Heskestad 公式的高度和热释放互逆 |
| `test_spread.py` | 蔓延速度外推到可燃物区域 |
| `test_vision.py` | 没有密钥时千问客户端失败；拒绝远程图片地址；非法字段失败 |

### web

在 `apps/web` 执行 `npm ci` 和 `npm run build`。构建前把 `config.example.json` 复制为 `config.json`。这一 job 做类型检查和打包，没有浏览器测试。

### firmware

用 g++ 编译并运行执行节点、报警节点的协议测试，再用 PlatformIO 编译 `firmware/esp32_actuator` 和 `firmware/esp32_panel`。协议测试覆盖的报文包括 `HELLO`、`PING`、错误格式、超时长、超角度限位和急停。编译通过不表示电路板已经接过。

### ml

`python -m pytest ml/tests`。`test_training_v3.py` 检查数据划分与审计、训练恢复和导出的脚本行为、指标与小目标及负样本的对应关系，以及 COCO 背景图筛选。它不重新训练 YOLO，也不产生新的 mAP。

## 3. 离线模型评测

数字来自 2026-11-08 交接，写入 `docs/project/STATUS.md` 和 `docs/training/yolo26s-handoff-2026-11-08.md`。本次没有重新跑评测。同一测试集：

| 模型 | D-Fire mAP50 | D-Fire mAP50-95 | COCO 背景误报图片数，confidence 0.25 |
|---|---:|---:|---:|
| YOLO11s 基线 | 0.745 | 0.432 | 39/334 |
| YOLO26s 正式 | 0.733 | 0.428 | 10/334 |
| YOLO26s 微调 | 0.731 | 0.419 | 6/334 |

微调减少了这组背景图片上的误报，D-Fire mAP 同时下降。IFireSmoke 测试集只有 6 张，交接说明它不能用来说明泛化。在线阈值是火焰 0.30、烟雾 0.35，不是上表的 0.25。

权重文件不在 Git 中。交接记录的微调 `best.pt` SHA-256 是 `429f7107d8810d912ab919f85285525eb8d8b167c050eb7b8450ea8f0772d027`。部署时应对本机文件再计算一次。

## 4. 合成实验

各目录的 `result.json` 都有 `data` 字段。下表只摘已经写进仓库的数，完整小数以 JSON 为准。

### 可变布局定位

`docs/experiments/2026-11-08-variable-layout.json`。120 个合成布局，像素噪声标准差 2，控制点噪声标准差 1。文件写明没有图像匹配，也没有 YOLO。

| 方法 | 样本数 | 均值（米） | P90（米） | 最大（米） |
|---|---:|---:|---:|---:|
| stale_pose | 120 | 0.565 | 0.900 | 1.515 |
| current_pose_linear | 120 | 0.098 | 0.225 | 0.328 |
| current_pose_robust | 120 | 0.013 | 0.020 | 0.035 |
| oracle_pose | 120 | 0.013 | 0.020 | 0.038 |

条件数 95% 椭球覆盖率为 0.983。这组数比较的是已知真值上的几何方法，不是教室实测。

### 2026-11-15 定位误差

`docs/experiments/2026-11-15-localization/result.json`，`data` 为「合成数据」，来源是 `triangulate` 加像素噪声。全体 36 点：均值 0.009985 米，P90 0.016797 米，最大 0.022607 米。按相机数的均值：2 路 0.0131 米，3 路 0.0097 米，4 路 0.0072 米。

### 云台和弹道

当前文件是 `docs/experiments/2026-11-15-gimbal-ballistics-noise/result.json`，合成数据，8 个种子。生成用的阻力和反解用的名义阻力不是同一个数：生成阻力是名义值 0.05 的 2 倍，另加出口速度抖动和落点噪声。三组都用 `solve_aim`，不再按视线瞄准。

| 方法 | 次数 | 均值（米） | 标准差（米） | P90（米） | 最大（米） |
|---|---:|---:|---:|---:|---:|
| 人工位姿加名义弹道 | 8 | 0.123 | 0.064 | 0.190 | 0.262 |
| 自标定加名义弹道 | 8 | 0.110 | 0.028 | 0.147 | 0.152 |
| 自标定加试喷拟合弹道 | 8 | 0.046 | 0.020 | 0.073 | 0.082 |

完整小数在 JSON 的 `hit_error_m`。自标定没有比人工位姿更差；名义阻力本身和生成模型不一致，前两组均值接近。试喷拟合把误差降到大约 5 厘米。12 到 36 组激光样本的收敛曲线都在 0.05 米附近。参数依据写在该文件的 `basis` 和 `docs/experiments/README.md`。这不是出水实测。

更早一份无噪声、按视线瞄准的 `2026-11-15-gimbal-ballistics/result.json` 已经不在仓库里。不要再引用其中 0.643 米、0.737 米和 0.003 米。

### 可信喷射

当前文件是 `docs/experiments/2026-11-15-trusted-spray-sigma/result.json`，合成数据。喷水半径 0.2 米，定位标准差从 0.05 米扫到 0.80 米，每个点 80 次。比较固定点、固定水平扫射、没有用水上限的 2σ 椭圆，以及落点不超过 3 个且名义覆盖概率不低于 0.5 才喷的椭圆。

标准差 0.05 米时四条路径命中率都是 1.0，用水 1 秒。0.10 米时，带门限的椭圆拒喷比例是 1，用水 0 秒；固定点命中率 0.7375，固定水平扫射 0.8125，无上限椭圆 0.2375。0.20 米时，无上限椭圆用水 16 秒，名义覆盖概率 0.5855，命中率 0.575；带门限的椭圆仍然拒喷，因为 16 个点超过 3 个落点的上限。

更早的 `2026-11-15-trusted-spray/result.json` 已不在仓库里。那份 16 次全部命中的结果不要再引用。现场喷水仍然待做。

### 延迟

`docs/experiments/2026-11-15-latency/result.json`，合成数据，剧本时钟，只有 `full` 一轮。因此 P50 等于 P90，也等于这一轮的时长：采集到检测 8 秒，检测到确认 25.875 秒，确认到定位 0 秒，定位到瞄准 0 秒，瞄准到喷射 3 秒。确认和定位发生在同一剧本帧。

同一次播放的墙钟在 `wall_clock_s`，从采集到喷射大约 1.19 秒。这是回放耗时，不是现场摄像头的延迟。多轮实测之前，不能从这一轮得出 P90。

### 千问固定假响应

`docs/experiments/2026-11-15-qwen-fixture/result.json` 的 `data` 是「固定假响应」，说明写明不是千问的真实评测结论。6 条假样本：直接询问的类别准确率 0.667，不安全建议率 1.0；证据加规则的类别准确率 0.833，不安全建议率 0，漏报率 0.2。费用是 null。规则表没有从画面证据单独推出 C 类的条目，这类样本会记成类别错误。

这些比例只说明脚本和规则表能够读入假响应。不能写成模型准确率。

### 热释放

`docs/experiments/2026-11-15-nist-hrr/result.json`，合成数据，来源是 t² 反算的火焰高度。相对误差均值约 2.4×10⁻¹⁶，是公式往返的数值误差，不是测量误差。增长档位的给定值和估计值都是 ultrafast。100 kW 的到达时间误差约 -0.91 秒；序列没有到达 500 kW，该档 `reached` 为 false。

NIST 试验的下载方式见 `docs/experiments/nist-fcd.md`。仓库里这份结果没有使用 NIST 的实测曲线。
