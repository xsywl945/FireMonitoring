## M2 当前训练记录

- 训练数据版本：`primary_fire_smoke_v2`，类别固定为 `0=fire`、`1=smoke`；
- 主划分：训练 17,977 张、验证 471 张、测试 500 张；独立审计为 0 错误、0 警告、0 跨划分近重复；
- 预训练权重：官方 `yolo11s.pt`，SHA-256 已写入实验请求文件；
- 训练代码版本：Git 提交 `4bcb74c`，云端训练包清洁且校验通过；
- 冒烟训练：10% 数据、10 epoch，退出码 0；该顺序子集偏向背景图，只验收训练链路，不评价精度；
- 正式训练：RTX 4090、640 像素、自动 batch 26、RAM 缓存、最多 100 epoch、patience 20；
- 正式首轮：Precision 0.711、Recall 0.559、mAP50 0.651、mAP50-95 0.341；
- 云端数据盘不是长期归档位置，实例释放前必须把 `best.pt`、结果 CSV、图表、实验元数据和导出模型下载到本地。

## M1 退出标准

- 三个应用均可在隔离环境构建和测试；
- 一键脚本可启动、检查和停止本地服务；
- 推理事件不直接写 MySQL，而是通过版本化 Redis Stream 进入业务服务；
- 云 API 或短信尚未配置时不影响基础告警；
- 演示数据明确为安全回放，不需要制造真实火焰或烟雾。

## 风险与约束

- 当前 `probe` 是配置级探测，不能替代真实 RTSP/DirectShow 连通性检查；
- MediaMTX 已能接收/播放流，但推理服务尚未读取实时流；
- 多模态适配器已实现严格结构化校验，尚未用真实 Key 做端到端验收；
- 短信属于外部有成本操作，必须在签名模板审核和白名单确认后再布防。
