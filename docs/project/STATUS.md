## M1 退出标准

- 三个应用均可在隔离环境构建和测试；
- 一键脚本可启动、检查和停止本地服务；
- 推理事件不直接写 MySQL，而是通过版本化 Redis Stream 进入业务服务；
- 云端复核门控启用时，云 API 不可用会阻止正式预警；该行为仅用于当前科研演示需求；
- 演示数据明确为安全回放，不需要制造真实火焰或烟雾。

## 风险与约束

- 当前 `probe` 是配置级探测，不能替代真实 RTSP/DirectShow 连通性检查；
- 当前实时推理由 Python 直接拥有 DirectShow 摄像头，并通过本地 MJPEG 向网页提供标注画面；MediaMTX 留给后续网络摄像头路径；
- 多模态适配器已完成真实收费端到端验收；严格门控在断网或云 API 故障时存在漏报风险；
- 短信属于外部有成本操作，必须在签名模板审核和白名单确认后再布防。
