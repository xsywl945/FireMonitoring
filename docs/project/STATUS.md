## M1 退出标准

- 三个应用均可在隔离环境构建和测试；
- 一键脚本可启动、检查和停止本地服务；
- 推理事件不直接写 MySQL，而是通过版本化 Redis Stream 进入业务服务；
- 云 API 或短信尚未配置时不影响基础告警；
- 演示数据明确为安全回放，不需要制造真实火焰或烟雾。

## 风险与约束

- 当前 `probe` 是配置级探测，不能替代真实 RTSP/DirectShow 连通性检查；
- MediaMTX 已能接收/播放流，但推理服务尚未读取实时流；
- 多模态适配器已实现严格结构化校验，尚未用真实 Key 做端到端验收；
- 短信属于外部有成本操作，必须在签名模板审核和白名单确认后再布防。
