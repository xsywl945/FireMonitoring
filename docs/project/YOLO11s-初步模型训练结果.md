# YOLO11s 初步火焰与烟雾检测模型训练结果

## 1. 实验目标

本阶段面向教室与实验室火灾监控的第一层视觉感知任务，训练一个可同时定位火焰与烟雾的双类别目标检测基线。模型输出作为后续单摄时序证据、双摄决策融合和多模态语义研判的输入，不直接承担最终火灾告警决策。

## 2. 数据与质量控制

- 数据来源：D-Fire、IFireSmoke；
- 统一类别：`0=fire`、`1=smoke`；
- 主划分：训练集 17,977 张、验证集 471 张、独立测试集 500 张；
- D-Fire 标签修复：丢弃 18 个零面积框，裁剪 379 个轻微越界框；
- 跨划分近重复处理：去除或隔离 174 个泄漏样本；
- 最终审计：0 错误、0 警告、0 精确重复、0 感知近重复。

D-Fire 官方划分包含连续视频帧近重复，因此训练早停和主测试指标不使用 D-Fire 官方验证/测试划分；D-Fire 测试结果仅作为跨来源补充指标。

## 5. 结果分析

训练损失持续下降，验证损失在约第 49 epoch 后趋于稳定并轻微回升，早停避免了继续训练带来的过拟合。独立 IFireSmoke 测试表明烟雾检测较强，而火焰在严格 IoU 条件下的定位精度仍是主要短板。

D-Fire 的 mAP50-95 比 IFireSmoke 低约 0.258，说明模型存在明显的来源域差异。后续应优先采集或构建以下数据：

- 教室和实验室真实摄像头视角；
- 远距离小火焰、早期弱烟和局部遮挡；
- 灯光、夕阳、屏幕火焰、红色物体等困难负样本；
- 蒸汽、雾气、粉尘和人员走动；
- 不同分辨率、曝光、帧率和压缩质量的视频。

验证集综合 F1 峰值约为 0.91，对应置信度约 0.467。该阈值只能作为单帧实验参考，部署时应在真实视频回放上重新标定，并与 N/M 时序判定、双摄融合和多模态复核共同使用。

## 6. 模型导出与一致性验证

已保留 `best.pt`、`last.pt` 和 `best.onnx`。ONNX 使用 FP32、opset 17、固定输入 `[1,3,640,640]`，输出 `[1,6,8400]`。

ONNX checker 已通过。在一个产生实际火焰检测的独立测试样例上：

- PyTorch：fire，confidence 0.434384；
- ONNX：fire，confidence 0.434481；
- 置信度差小于 0.001，检测框坐标差小于 0.5 像素。

这说明导出前后的核心检测结果一致。Windows RTX 5060 Laptop 上仍需单独完成 PyTorch/ONNX Runtime 的速度、显存和双路视频压力测试。

## 7. 局限与安全声明

- 当前独立测试集仍以公开数据为主，不能代表真实教室和实验室全部分布；
- D-Fire 补充指标受连续帧近重复影响，不能作为完全独立泛化结论；
- 模型尚未完成真实摄像头困难负样本回归和告警阈值标定；
- 该模型是科研演示组件，不能替代认证烟感、温感或消防报警设备，不能作为唯一生命安全链路。
