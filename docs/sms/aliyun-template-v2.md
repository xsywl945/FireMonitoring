# 阿里云短信模板 v2

告警研判完成后发送。签名和模板都在阿里云短信控制台申请，模板通过后再把 `template_code` 写进 `config.json`。

## 模板正文

```
${location}发生火情，等级${level}。建议：${method}。请立即处置。
```

变量名只用英文：

| 变量 | 含义 | 示例 |
|---|---|---|
| `location` | 教室或房间名称 | `教学楼A101` |
| `level` | 系统自定义等级，Ⅰ级到Ⅳ级 | `Ⅲ级` |
| `method` | 规则表给出的短句，含建议灭火方式和禁止项 | `先断电，干粉或二氧化碳，禁水` |

## 长度

阿里云通知类短信的变量名一般不超过 20 个字符。单个变量的取值按当前模板规范不超过 35 个字符，不能是链接、电话、QQ 或微信，模板也不能整句都由变量拼成。上面的正文有固定汉字，三个变量都由后端按 35 个字符封顶，超长直接失败，不截断后照发。

等级固定为「Ⅰ级」「Ⅱ级」「Ⅲ级」「Ⅳ级」。建议灭火方式来自 `config/fire_rules.json` 里各类的短句，多类同时出现时用最严格那一类的短句，并尽量补上「先断电」「先关气源」。教室名称如果超过 35 个字，这条短信不会发出。
