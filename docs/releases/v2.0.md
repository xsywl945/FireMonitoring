- P6：值班处置、导出、告警片段、账号和可修改的非密钥配置。
- P7：离线演示模式、数据大屏和数字孪生。演示材料是合成数据。
- P8：定位、云台弹道、可信喷射、延迟、千问假响应和热释放的实验脚本。提交进仓库的 2026-11-15 结果是合成数据或固定假响应。
