# 高精度火灾模型升级与大模型门控计划

## 结论

当前 YOLO11s 适合作为初步基线，不适合作为“效果特别好”的最终模型。它在 IFireSmoke 独立测试上的 mAP50-95 为 0.702，但在 D-Fire 跨来源测试上降到 0.444，其中火焰 Recall 仅 0.650，说明主要问题是数据域差异与困难负样本不足，而不是单纯模型参数量不够。

下一版采用以下组合：

1. 本地检测主模型候选为 `YOLO26m @ 960`，RTX 4090/5090 训练；
2. 若小火焰仍明显漏检，再做 `YOLO26 P2 @ 960` 对照实验；
3. Windows RTX 5060 以 5 FPS 抽帧部署，优先使用准确率更高的 one-to-many 检测头；
4. YOLO 通过 3/5 帧后，提交最近 3 帧给 `qwen3.7-plus` 做正式报警前复核；
5. `qwen3.7-max-2026-06-08` 仅作为付费 A/B 候选，必须在同一门控回归集上优于 Plus 才切换。

模型升级不能替代数据升级。公开数据用于预训练，教室、实验室和本机摄像头场景数据决定最终效果。

## 数据集 v3

保留并重新审计现有 D-Fire、IFireSmoke；新增 FASDD_CV 作为大规模主数据，并建立目标场景专项集：

- 正样本：室内早期小火焰、远距离火焰、薄烟、逆光烟雾、局部遮挡、电气设备附近烟火；
- 困难负样本：投影屏/显示器/手机中的火灾画面、红橙灯光、夕阳与强反光、焊接、蒸汽、加湿器、粉尘、雾气、云、红色衣物；
- 日常负样本：目标教室和实验室在白天、夜间、开灯、关灯、人员走动等状态下的正常视频；
- 目标场景测试集：按教室/实验室和视频来源分组，整段视频只能进入一个划分，禁止相邻帧跨训练/测试泄漏。

建议先收集至少 5,000 张目标场景困难负样本和 1,000 个短视频片段。公开数据中的正样本与本地真实负样本共同训练；投影屏中出现的火焰必须标为背景，因为系统需要判断现场是否存在真实物理火焰。

## 检测模型实验矩阵

| 实验 | 模型 | 分辨率 | 目的 |
|---|---|---:|---|
| A | YOLO11s | 640 | 复现当前基线 |
| B | YOLO26s | 960 | 验证新训练配方和小目标覆盖 |
| C | YOLO26m | 960 | 精度优先主候选 |
| D | YOLO26 P2 | 960 | 小火焰专项候选，仅在 C 仍漏检时运行 |

所有模型必须使用完全相同的 v3 划分、随机种子和评测脚本。不要仅看总体 mAP，必须分别报告 fire/smoke 的 Precision、Recall、mAP50、mAP50-95，以及目标场景每摄像头小时误报数。

RTX 5060 最终选择规则：在单路 5 FPS、显存稳定且温度可接受的前提下选择目标场景 Recall 最高的模型；若 YOLO26m@960 超出 8GB 显存或长期不稳定，再退到 YOLO26s@960，而不是直接降低数据质量要求。

## 大模型门控 A/B

建立至少 500 条候选事件的人工标注回归集，每条包含 3 个连续帧，并标注：

- 是否为现场真实物理火焰；
- 是否为现场真实物理烟雾；
- 是否应正式报警；
- 主要误报类型；
- 场景风险和可见火源性质。

在完全相同的提示词、图片和 JSON 校验下对比 `qwen3.7-plus` 与 `qwen3.7-max-2026-06-08`。主要指标依次为：危险事件漏判率、困难负样本误报率、结构化响应成功率、P95 延迟、单次费用。未经这组测试，不因 Max 名称更大就直接切换。

当前正式门控条件：

- 云端调用成功且结构校验通过；
- `hasVisibleFire=true` 或 `hasVisibleSmoke=true`；
- `confidence >= 0.70`；
- 否则只保留本地候选，不创建事故、不发站内报警；
- `INFERENCE_VLM_GATE_FAIL_OPEN=false`，云端故障不放行。

## 验收门槛

检测器目标：

- 目标场景 fire Recall ≥ 0.90；
- 目标场景 smoke Recall ≥ 0.90；
- 两类 Precision 均 ≥ 0.90；
- 困难负样本集每摄像头小时误报 ≤ 0.10 次；
- Windows 单路 5 FPS 连续运行 8 小时无崩溃、无显存持续增长。

端到端目标：

- 真实危险候选经大模型放行率 ≥ 0.95；
- 屏幕火焰、灯光、蒸汽等困难负样本拦截率 ≥ 0.98；
- 结构化输出成功率 ≥ 0.995；
- 云端复核 P95 延迟 ≤ 10 秒；
- 所有门控拒绝在日志中包含 trace、状态、可见火/烟判断、置信度和错误码，不记录 API Key 或 Base64 图片。

这些指标只用于科研原型验收。即使全部达到，也不能替代认证消防探测器或成为唯一生命安全报警链路。
