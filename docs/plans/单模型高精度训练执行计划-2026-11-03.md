# 多 Agent 模型训练协作计划

日期：2026-11-03。状态：历史计划，已被实际执行的 YOLO26s@640 训练替代。结果与当前分工见 [训练交接](../training/yolo26s-handoff-2026-11-08.md)和[协作说明](../training/collaboration.md)。下文保留原计划，不代表当前任务。

## 目标

只训练一个 **YOLO26m@960** 火焰与烟雾检测模型，类别固定为 `0=fire`、`1=smoke`。既要独立数据集指标好，也要在室内、小火焰、薄烟和复杂背景上识别可靠。

训练环境：RTX 4090D 24GB、15 vCPU、80GB 内存，Python 3.12、PyTorch 2.8.0、CUDA 12.8。后续在 RTX 5060 Laptop 约 8GB 显存上使用；当前只完成模型训练，不开展系统部署。

## 执行顺序

1. **准备数据。** 复审 D-Fire、IFireSmoke，核实并接入 FASDD_CV；补充室内小火焰、弱烟及屏幕火焰、灯光、反光、蒸汽等困难样本。不能只追求数量。
2. **清洗与划分。** 统一类别、修复坏框与漏标；每来源分层抽检约 300 张。按视频和场景分组并跨来源去重，禁止相邻帧进入不同划分。训练、验证、测试分别锁定并保存清单与 hash。
3. **检查训练链路。** 使用同一模型做 2–3 epoch 小样本健康检查，确认标签、显存、保存与恢复正常。该检查不作精度结论。
4. **正式训练。** 从官方预训练权重开始，960 输入、AMP、batch 从 8 起测，最多 150 epoch、早停 25、seed 42。温和增强，缓存默认关闭；固定实际配置和依赖版本。
5. **改进同一模型。** 根据训练和验证集的错误补数据、修标签；必要时对同架构权重低学习率微调。不安排多模型对照，不盲目增加轮数。
6. **冻结与验收。** 只用验证集选择权重和阈值，再运行独立测试。按来源、fire/smoke、小目标和困难场景分别报告，交付一个正式 `best.pt`。

## 结合现有代码要处理的问题

- `prepare_fire_smoke_v1.py` 目前只支持两个来源，需补充新来源与场景元数据，注意原始类别顺序不同。
- `build_leakage_safe_primary_split.py` 固定 IFireSmoke 验证/测试各 500 张，需完善通用分组划分；审计里的近重复 warning 必须有处置记录。
- `train_baseline.py` 需支持新训练配置、可靠恢复及初始化权重 hash；不能照搬旧 RAM 缓存默认值。
- `validate_model.py` 需补充冻结阈值、分组指标及错误案例，避免同名数据 YAML 的汇总冲突。
- 上传包需包含新增配置。具体参数先核对固定的 Ultralytics 8.4.100，兼容性有问题再调整版本。
