# 双 UVC 摄像头与自动喷水基础功能

## 2026-10-18 当前需求更新

本节覆盖下文原有强制云端门控要求：大模型调用暂时关闭，保留可重新启用接口和历史结果；实时本地 YOLO 火焰达到时序确认后自动喷水。烟雾单独提示，不启动水泵。支持单摄和双摄独立运行，共享泵与冷却。BOOT/GPIO0 运行时按住强制喷水，松开停止，单次最多 30 秒；STOP 优先，持续按住不能撤销 STOP。默认自动运行 5 秒。用户已确认当前只接一只 UVC、烧录期间 12V 断开。

本次需求：保留账号、教室和摄像头管理；删除人工审核与人工事件状态流转；实现火灾识别、大模型检测、自动启动水泵喷水。

## 实现边界

- 两个 UVC 摄像头接 Windows 主机，最多同时运行两路独立 YOLO + 时序识别；可绑定同一教室两个视角或不同教室。每路大模型复核独立，不要求两路同时检出。
- ESP32 通过 CH340 USB 串口接主机，用 GPIO 驱动外部 MOSFET 模块，控制 12V 25W 泵。摄像头不接 ESP32。
- 一只泵只覆盖配置的一个教室。仅真实实时检测、近期证据、成功且达到置信度阈值的大模型正向判断才允许启动。模拟回放、云端失败和否定判断不能启动。
- 单次运行默认 5 秒，固件上限 30 秒；共享冷却时间默认 60 秒。双视角不能重复延长运行。指令有唯一标识，主机在发送前持久化，失败不自动重发。
- 固件上电关闭，运行超时关闭；失去主机心跳关闭。页面支持紧急停止并锁定后续自动启动，重新启动服务才解除锁定。
- 页面展示控制器状态和持久化指令记录，不能将 GPIO 回执当作水流反馈。没有流量传感器，不声称实际喷水或灭火成功。
- 移除人工确认、处置、解决、误报操作及其 HTTP 写接口；历史事件和证据仍可读取。
- 提供接线说明、ESP32 固件、串口配置及实机验收步骤。板载 0.96 屏幕型号未知，不为它增加强制依赖。
