# FIRE_PANEL_V2

报警节点（ESP32-B）与主机之间的串口协议。115200 波特，8N1，一行一条命令，以 LF 结束，CR 忽略。灯光闪烁由固件按 2 Hz 产生，主机只下发模式。

| 主机发送 | 回复 | 含义 |
|---|---|---|
| `HELLO` | `READY FIRE_PANEL_V2` | 识别固件 |
| `PING` | `PONG` | 心跳 |
| `STATUS` | `STATE <模式> <静音> <链路>` | 模式见下表。静音是 `MUTE` 或 `OPEN`。链路是 `UP` 或 `DOWN` |
| `MODE <名称>` | `MODE <名称>` | 设置主机希望的模式 |
| 未知模式 | `ERR MODE` | 模式不变 |

模式：

| 名称 | 灯 | 蜂鸣 |
|---|---|---|
| `OFF` | 全灭 | 关 |
| `GREEN` | 绿常亮 | 关 |
| `YELLOW` | 黄闪 | 关 |
| `RED_BLINK` | 红闪 | 开 |
| `RED_SOLID` | 红常亮 | 开 |
| `ALT` | 黄、红交替 | 开 |

静音键只翻转蜂鸣，不改灯，也不改模式。主机报文不能代替这个键。

任意合法命令都把链路视为 `UP`，并恢复主机上次下发的模式。3000 ms 没有主机命令时，固件自己改成 `ALT`，链路上报为 `DOWN`，直到下一条主机命令。

屏幕驱动在 `firmware/esp32_panel/src/display_ssd1306.cpp`。协议逻辑只调用 `displayShow`，换屏时替换这个文件。
